# IApessoal 1.0 no Expo Go para iPhone

Abra a [página da prévia](https://iapessoal-preview-v1.km-prospect-ai-app.workers.dev/) no Safari e toque em **Abrir no Expo Go**.

Use o Expo Go com suporte ao SDK 58. Copie o endereço e abra no Safari, ou cole em **Enter URL manually** no Expo Go, se disponível.

```text
exps://iapessoal-preview-v1.km-prospect-ai-app.workers.dev/manifest-v1.json
```

A prévia foi exportada a partir da tag v1.0.0 com dependências Expo compatíveis com iOS. O código do aplicativo foi preservado. Em `build-config/` estão os arquivos de configuração e o lockfile usados para gerar o bundle.

Memórias, Laboratório e ajustes locais ficam disponíveis sem configurar o gateway. Respostas de IA dependem de um gateway HTTPS configurado por você. Expo Go não incorpora o módulo opcional de ditado da build nativa própria. O ditado do teclado do iPhone pode ser usado para preencher o campo.
