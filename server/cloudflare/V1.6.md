# IA Pessoal 1.6

A prévia 1.6 usa o mesmo escopo local do Expo Go e o mesmo gateway da 1.5. A URL da prévia 1.5 e os registros anteriores continuam disponíveis. O backend 1.6 foi ativado no gateway compartilhado, com alterações aditivas para manter o cliente 1.5 compatível. O gateway usa a GitHub App de leitura, a fila e o Cron existentes. Não execute código de repositórios nem conceda permissões de escrita à integração.

Em **Projetos → Repositórios GitHub**, abra **Ver histórico** para ver o mapa técnico observado, os trechos examinados, o consumo quando disponível e as referências ao commit. Use a **Central de descobertas** para filtrar os resultados carregados, consultar outras páginas e confirmar uma resolução após verificar a evidência. Atualizar resultados apenas lê o histórico.

O Worker usa caminhos e metadados para identificar papéis de arquivos, e lê seletivamente manifestos elegíveis. Tecnologias inferidas a partir da árvore são tratadas como indícios. A cobertura registra repositório, commit, caminho, execução e linhas apresentadas ao modelo. É contabilizada após uma resposta válida. O monitor evita repetir os arquivos já apresentados no mesmo commit e, quando há arquivos elegíveis restantes, volta a investigá-los nas próximas verificações. Uma mudança no trecho anterior é registrada como possível correção e exige confirmação humana.

A migração acrescenta `github_coverage_v16` e `github_finding_priority_v16`. O histórico anterior segue no formato existente. O novo mapa técnico e as correções potenciais ficam no relatório cifrado. As métricas de cobertura contam arquivos registrados pela 1.6. A IA distingue hipóteses, problemas prováveis e oportunidades. Uma confirmação depende de evidência adicional ou verificação humana.

O orçamento continua em até duas inferências e 800 Neurons reservados por dia para o monitor. Cada rodada examina até quatro arquivos, até 3.400 caracteres iniciais de cada arquivo e até 2.500 entradas da árvore para seleção. O GitHub também pode truncar a árvore. Alguns arquivos ficam fora do escopo por tamanho, formato ou conteúdo sensível. A ausência de descobertas só descreve os trechos examinados. O sistema não executa testes do repositório.

Para reverter o código, volte à versão anterior em **Workers & Pages → iapessoal-gateway-v15 → Deployments**. O rollback de código conserva as tabelas aditivas e os dados gravados após a publicação. Restaurar o banco é uma operação à parte.
